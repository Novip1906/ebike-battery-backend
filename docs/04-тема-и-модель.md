# Тема 10 (Транспорт) — модель предметной области

**Формулировка из `topics.md`:** «Оценка времени разряда аккумулятора электровелосипеда. Услуги — режимы работы мотора (Eco, Tour, Sport, Turbo), заявка — расчет оставшегося заряда аккумулятора после поездки по маршруту с заданным перепадом высот и выбранными режимами».

## Соответствие сущностей курса и темы

| Сущность курса | Имя в теме | Имя в коде / таблице |
|---|---|---|
| услуга | режим работы мотора | `MotorMode` / `motor_mode` |
| заявка (с ЛР2) | расчёт разряда аккумулятора на маршруте | `battery_calculation` |

## Поля по теме

**Режим работы мотора** (помимо обязательных: название, краткое описание, статус, ключ изображения, ключ видео):
- `support_percent` — максимальная поддержка мотора, % (официальные значения Bosch);
- `consumption_wh_per_km` — расход батареи, Вт·ч/км (**числовое поле фильтрации** на странице плитки);
- `max_torque_nm` — максимальный момент привода, Н·м;
- `drive_unit` — привод, для которого доступен режим;
- `support_character` — характер поддержки (постоянная, спортивная, автоматическая).

**Заявка (ЛР2 и далее):** длина маршрута `route_length_km`, суммарный набор высоты `elevation_gain_m`, ёмкость аккумулятора `battery_capacity_wh`, масса велосипедиста с велосипедом `total_mass_kg`.

**Связь м-м:** `rider_comment` — текстовый комментарий (ручной ввод), `remaining_charge_wh` — остаток заряда, заполняется автоматически при статусе «Завершён».

## Расчёт (для ЛР2–ЛР4 и ТЗ)

Энергия из аккумулятора складывается из движения по горизонтали и набора высоты:

```
E_ride  = consumption_wh_per_km × route_length_km
E_climb = m × g × Δh / (3600 × η)
E_total = E_ride + E_climb
remaining_charge_wh = battery_capacity_wh − E_total
```

где `m` — масса велосипедиста с велосипедом, кг; `g` = 9.81 м/с²; `Δh` — набор высоты, м; `η` ≈ 0.75 — КПД мотора и трансмиссии. Делитель 3600 переводит джоули в Вт·ч.

**Пример:** маршрут 40 км в режиме Tour (7.8 Вт·ч/км), набор высоты 300 м, масса 100 кг, аккумулятор PowerTube 800 Вт·ч.
`E_ride` = 312 Вт·ч; `E_climb` = 100 × 9.81 × 300 / (3600 × 0.75) = 109 Вт·ч; `E_total` = 421 Вт·ч; остаток ≈ **379 Вт·ч** (47 %).

Расход по режимам согласован с запасом хода: 800 Вт·ч / 5.2 ≈ 150 км в Eco и 800 / 16.4 ≈ 49 км в Turbo, что соответствует данным производителя.
