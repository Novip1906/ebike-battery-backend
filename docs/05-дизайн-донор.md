# Донор дизайна — Bosch eBike Systems

Сайт: **bosch-ebike.com**. Выбран потому, что режимы Eco, Tour, Sport, Turbo из формулировки темы — это режимы системы Bosch eBike, то есть предметная область и донор совпадают.

Значения ниже взяты из рабочей таблицы стилей сайта (`bosch.<hash>.css`), это не «на глаз».

## Три цвета с точными кодами

| Роль в приложении | HEX | Токен Bosch |
|---|---|---|
| Основной акцент: кнопки, активная вкладка, заголовки секций | `#007BC0` | `--bosch-blue-50` |
| Второй акцент: бейдж привода, статус «черновик», расход батареи | `#18837E` | `--bosch-turquoise-50` |
| Фон приложения | `#EFF1F2` | `--bosch-gray-95` |

Дополнительно: текст `#1A1C1D` (`gray-10`), подписи `#71767C` (`gray-50`), рамки `#E0E2E5` (`gray-90`).

## Hover и состояния кнопок

| Состояние | HEX | Токен Bosch |
|---|---|---|
| обычное | `#007BC0` | `major-accent__enabled__fill__default` |
| наведение | `#00629A` | `major-accent__enabled__fill__hovered` (`blue-40`) |
| нажатие | `#004975` | `major-accent__enabled__fill__pressed` (`blue-30`) |
| выключенная | фон `#E0E2E5`, текст `#71767C` | `major-accent__disabled` |

Карточка режима при наведении получает синюю рамку и тень `rgba(0,123,192,0.24)`.

## Форма карточек и шрифт

- скругление кнопок и полей ввода — `4px` (у Bosch `border-radius: .25rem` для `.button`);
- скругление карточек и секций — `8px` (у Bosch `.teaserbox-portrait__item { border-radius: .5rem }`);
- рамка карточки — 1px `#E0E2E5`;
- шрифт — `Bosch Sans`, запасные `Arial, Helvetica Neue, Helvetica` (ровно как в CSS донора).

Всё перечисленное собрано в блоке `:root` файла `static/css/motor_mode.css` — на защите показывать его рядом с открытым сайтом (скриншоты 8–9).
