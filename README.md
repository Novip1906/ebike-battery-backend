# ebike-battery-backend

Бэкенд заявочной системы по теме **«Оценка времени разряда аккумулятора электровелосипеда»**.
Курс «Разработка Интернет Приложений», ИУ5, 2026. Вариант 10 раздела «Транспорт, инфраструктура и строительство».

- **Услуга** — режим работы мотора (Eco, Tour, Sport, Turbo и другие режимы системы Bosch eBike).
- **Заявка** (со второй лабораторной) — расчёт остатка заряда аккумулятора после поездки по маршруту с заданным перепадом высот.
- **Роли** — велосипедист (`rider`) и инженер сервиса (`bike_service_engineer`).

## Стек

Go 1.26, gin, `html/template`, Minio в Docker. Без базы данных и без JavaScript — по заданию первой лабораторной.

## Запуск

```bash
docker compose up -d                 # Minio на портах 9000 (API) и 9001 (консоль)
./scripts/minio_setup.sh ../media    # создать публичный бакет и залить медиа
go run .                             # приложение на http://localhost:8080
```

Базовый адрес медиа берётся из `MINIO_PUBLIC_URL`, по умолчанию `http://localhost:9000/ebike-motor-media`.

## Маршруты

| Метод и URL | Контроллер | Назначение |
|---|---|---|
| `GET /motor-modes/feed[/:motor_mode_id]` | `MotorModeFeed` | Лента: вертикальное видео режима на весь экран, описание с раскрытием «Ещё» на `<details>`. Без `id` открывается первый режим, `?next=true` — следующий после указанного |
| `GET /motor-modes/draft` | `MotorModeDraft` | Страница добавления: черновик из коллекции, поля разделены на медиа, текст и параметры по теме |
| `GET /motor-modes` | `MotorModeGrid` | Плитка в 2 столбца, фильтр `?maxConsumptionWhPerKm=` по расходу батареи: слайдер со шкалой от минимума до максимума опубликованных режимов, по умолчанию стоит на максимуме и показывает все режимы |

## Структура

```
main.go                                    точка входа, маршрутизация и шаблоны
internal/ds/motor_mode.go                  модель режима, статусы, расчёт запаса хода
internal/repository/                        коллекция режимов в памяти, выборки и фильтр
internal/handler/                           три контроллера и таблица маршрутов
templates/                                  три страницы, панель вкладок, страница 404
static/css/motor_mode.css                   стили, палитра Bosch eBike
scripts/minio_setup.sh                       бакет ebike-motor-media и загрузка медиа
```

## Данные

14 режимов работы мотора: 12 опубликованных, один черновик (`Limit`), один удалённый (`Off`).
Проценты поддержки — официальные значения Bosch eBike; расход батареи в Вт·ч/км согласован с запасом хода на аккумуляторе PowerTube 800 Вт·ч.
Границы слайдера на плитке вычисляются по опубликованным режимам с расходом больше нуля: минимум берётся как есть (4.6), максимум округляется вверх до целого (20).
