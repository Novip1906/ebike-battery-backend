# Макет: как загрузить в Figma

Три артборда 390×844 лежат рядом: `01-lenta.svg`, `02-dobavlenie.svg`, `03-plitka.svg`.

## Импорт

1. Открыть Figma → **Drafts** → **Design file**.
2. Перетащить все три `.svg` прямо на холст (или File → Place image).
3. Figma разберёт каждый файл на слои: прямоугольники, изображения, текст остаётся редактируемым текстом.
4. Расставить артборды в ряд, переименовать страницы: «Лента», «Добавление», «Плитка».

Плагины и платные подписки не нужны — Figma читает SVG штатно.

## После импорта (5 минут)

- Выделить каждый артборд → **Frame** 390×844 (`Ctrl/Cmd+Alt+G`), если нужно превратить группу во фрейм.
- Шрифт указан `Arial` — это запасной шрифт из CSS Bosch. Если нужен вид один в один, поставить **Bosch Sans** и заменить в тексте.
- Цвета можно сохранить в стили: `#007BC0`, `#18837E`, `#EFF1F2` — те же, что в `static/css/motor_mode.css`.

Если преподаватель попросит показать, что макет и приложение совпадают: открыть рядом артборд и соответствующую страницу приложения на `localhost:8080` в мобильном разрешении (DevTools → 390×844).
